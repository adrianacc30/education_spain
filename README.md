# Education Policies and Wage Inequality in Spain

How do educational expansion and schooling resources relate to wage differences in Spain?

This project links historical education indicators (1900–2022) with seven waves of the Spanish Wage Structure Survey (1995–2022), using cohort-level wage regressions and nested CES accounting in Stata.

## Main findings

- Educational expansion is associated with lower wages in the main specification, but results are sensitive to demographic controls.
- Estimated relationships with schooling resources depend on how those resources are measured.
- Adjusting labour supplies for schooling quality leaves the model's implied demand paths broadly similar.
